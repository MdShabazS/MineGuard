# MineGuard — Budgets (Placeholder)

> **STATUS: `[PENDING]` — the four budgets are NOT created yet.**

This directory will eventually hold **four complete candidate Bills of Materials (BOMs)** for the
MineGuard onboard add-on system. The four configurations are:

- **Budget 1 — Top Quality**
- **Budget 2 — Full Featured**
- **Budget 3 — Thermal Only**
- **Budget 4 — Camera Only**

## Ground rules for the future budgets

- **Existing drone-platform hardware is excluded** from all four budgets
  (airframe, motors, ESCs, propellers, existing flight battery, CUAV V6+, existing flight GPS,
  existing telemetry/radio hardware, and any other components already belonging to the drone).
- **Each budget must be a complete operational BOM** of everything the MineGuard add-on system
  needs beyond the existing drone — not sensors only. This includes (only where technically
  justified) onboard computing, storage, cooling, power, power cables, sensors, sensor interface
  boards, USB hub, FC interface cable, UART/USB adapters, regulators/DC-DC converters,
  communication modules, mounts, camera/sensor mounting, connectors, cables, and any other
  integration hardware/accessories genuinely required.
- **Exact models and prices require research and verification.** Prices must be researched
  (reputable Indian sources preferred), not guessed; where a reliable price cannot be verified it
  must be marked `PENDING PRICE VERIFICATION`. Specifications must be supported by reliable sources.
- **Budgets are currently PENDING.** They will be created only after: (1) the project-guide scope
  decision (surface vs subsurface), (2) budget comparison, (3) compatibility verification,
  (4) physical bench testing, and (5) team review.
