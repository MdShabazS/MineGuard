## Delivered
- `package.json`: scripts `dev`, `build`, `start`, `test`, `typecheck`, `task-gate`
- `shared/protocol.ts`: shared health and socket event types
- `server/src/app.ts`, `server/src/index.ts`: Express app with `GET /api/health`, a JSON 404 for unknown `/api/*` paths and a Socket.IO server (`server:hello`, `system:ping` ack). It serves `client/dist` on the same origin once the client is built.

- `client/vite.config.ts`: in dev, the Vite proxy forwards `/api` and `/socket.io` (WebSocket) to Express on :3000.
- `server/test/smoke.test.ts`: automated smoke tests
- Docs: README "Run locally" and "Code layout" sections; docs/API_CONTRACT.md "Implemented (MG-001)" section
