## Delivered
- `shared/world.ts`: the single world definition `mg-field-01` (200 × 200 virtual units), with hills, 2 roads, 140 trees from a fixed random seed, and 3 landmarks. It also has the coordinate helpers (`worldToScene`, `sceneToWorld`, `isInBounds`, `roundCoord`, `terrainHeight`) and an integrity checksum.
- `server/src/app.ts`: `GET /api/world` serves that one definition to every client.
- `client/src/world/`: React Three Fiber scene.
  - `Terrain.tsx`: height-mapped mesh coloured by height.
  - `Features.tsx`: roads, instanced trees, landmarks (the pond follows the terrain), survey boundary and corner X/Z labels.
  - `WorldView.tsx`: canvas, orbit/zoom/pan, hover and click coordinate readout, click marker. A pointer drag over 4 px counts as an orbit, not a click.
  - `useWorld.ts`: loads the world and verifies its checksum.
- Red (`/red`) and Blue (`/blue`) portals both render `WorldView`.
- Tests: `server/test/world.test.ts` (8 tests) and `tests/e2e/world.e2e.ts` (2 browser tests). New script: `npm run test:e2e`.
- Docs: the coordinate system section in docs/ARCHITECTURE.md, `/api/world` in docs/API_CONTRACT.md, and README updates.
- Works offline: no CDN fonts, textures or HDR files. Every asset is bundled or generated.

## Coordinate system (for MG-003 onward)
- World X, Z each run from 0 to 200, in fictional virtual units (not GPS). Y is the terrain height.
- Scene position = (x − 100, y, z − 100): world (0,0) is scene (−100, −100), and world (100,100) is the scene origin.
- Precision is 0.1 unit. Out-of-range or non-finite values are rejected by `isInBounds`.
